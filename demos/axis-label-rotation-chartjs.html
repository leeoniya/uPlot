Random labels: Chart.js rotation and automatic layout

This subset of the original uPlot demo uses Chart.js 4.5.1. See also the ECharts demo. Chart.js and its datalabels plugin load from a CDN and require network access.

Randomize data generates 3–15 one-to-three-word labels and two series with random offsets and spreads across different magnitudes. The other controls keep the data unchanged. Chart height stays at 500px. Horizontal category labels stay unrotated.

The ?seed=<seed> URL parameter reproduces the same labels and values across all three demos. The 🔗 button copies a URL for the current data, without layout settings. Randomize data chooses a new seed.

Chart.js sets the axis space and padding automatically. This demo uses its native rotation range of 0° to 90°. Category labels stay complete and visible, so neighboring labels can overlap. The datalabels plugin centers values on bars or stacked segments and hides overlapping value labels.

Percent mode uses separate positive and negative totals for each category. Tooltips show original values and signed percentages. The legend does not hide series.
