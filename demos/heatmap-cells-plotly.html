Sparse heatmap · Plotly.js 4.1.2

A native raster heatmap using the same synthetic dataset (~250k generated cells) and colors as the uPlot, ECharts, and ECharts GL demos.

Plotly uses a dense count matrix with empty entries for missing cells and explicit coordinate edges. Datetime X and logarithmic Y axes show the positive log view. Smoothing and gap interpolation are disabled.
