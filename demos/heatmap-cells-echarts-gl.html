Sparse heatmap · ECharts 6.1.0 + GL 2.1.0

Experimental WebGL counterpart to the uPlot demo and native ECharts heatmap, using the same synthetic dataset (~250k generated cells) and colors. Both libraries load from a CDN. Network access and WebGL are required.

ECharts GL draws rectangular scatter symbols, not native heatmap cells. Thin symbols and large zoomed cells can render differently. Hover uses the data grid, not GL symbol hitboxes. Progressive rendering is disabled to preserve per-cell colors.

Equal-width time categories and equal-height exponential bucket categories preserve gaps and log-view spacing. Linear/asinh Y scales and negative mirroring are not supported here. Axis labels mark category centers; hover shows original cell bounds.
