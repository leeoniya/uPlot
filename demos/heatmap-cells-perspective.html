Sparse heatmap · Perspective 5.5.1

A native WebGL heatmap using the same synthetic dataset (~250k generated cells) as the uPlot, ECharts, and ECharts GL demos.

Perspective pivots the precomputed counts by time and bucket. Its uniform numeric bands use time centers and log₂ bucket centers; Y labels are log₂(seconds), not seconds. Missing numeric positions retain their gaps. Native hover shows centers and counts, not interval bounds; dates use the browser’s local time zone. Wheel to zoom, drag to pan, and use Reset Zoom to reset.

The color controls change the native gradient, not the counts. Perspective samples that gradient into a GPU texture, so colors near palette boundaries can differ slightly from the other demos. No custom renderer or hover layer is used.
