Issue 1133: dynamic backend range

GitHub issue #1133

All three updates use the same configuration. Y follows backendRange without a Y extrema scan.

Data updates alternate between two shapes with identical X values. Range updates alternate between [0, 10] and [0, 20].

Both shapes fit within both ranges. You can repeat each button or mix the scenarios in any order.

Relevant configuration

const initialData = [[0, 1, 2, 3, 4], [2, 8, 3, 7, 4]];
const replacementData = [[0, 1, 2, 3, 4], [8, 2, 7, 3, 6]];
let backendRange = [0, 10];

const opts = {
  scales: {
    x: { time: false },
    y: {
      // auto defaults to true, so setData() and redraw() recalculate Y.
      // This optional callback prevents Y auto-ranging after an explicit X range.
      // It also prevents redraw() from recalculating Y.
      // auto: (u, viaAutoScaleX) => viaAutoScaleX,
      // The backend supplies the range, so scan:false avoids a Y extrema scan.
      scan: false,
      range: () => backendRange,
    },
  },
};

Data only

The data changes. Y keeps the current backend bounds.

const nextData = u.data === initialData
  ? replacementData
  : initialData;
u.setData(nextData);

Backend range and data

Both change. setData() alone applies the new backend bounds.

backendRange = [0, backendRange[1] === 10 ? 20 : 10];
const nextData = u.data === initialData
  ? replacementData
  : initialData;
u.setData(nextData);

Backend range only

The data stays unchanged. redraw() applies the new backend bounds with the default auto:true.

backendRange = [0, backendRange[1] === 10 ? 20 : 10];
u.redraw();
