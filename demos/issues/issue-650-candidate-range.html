Issue 650: calculate a candidate range without applying it

GitHub issue #650

X starts zoomed to [0, 1]. Click Outlier in the legend to show or hide it. Its largest value is outside the zoom.

The legend toggle recalculates Y for the current X window. The query runs afterward and leaves the view unchanged.

This example calculates full-domain bounds for one independent Y scale with the default ranger, not a general reset dry run. Expected candidates: [8, 32] with Outlier hidden and [0, 330] with Outlier shown.

Relevant configuration

const opts = {
  scales: {
    x: { time: false },
    y: {},
  },
  series: [
    {},
    { label: "Values", stroke: "blue" },
    { label: "Outlier", stroke: "red", show: false },
  ],
};

const [dataMin, dataMax] = uPlot.scan(u, "y");
const candidateRange = u.scales.y.range(u, dataMin, dataMax, "y");
