Issue 915: reset a zoomed static Y range

GitHub issue #915

Drag a rectangle inside the chart. Then double-click the chart.

Double-click restores X and the configured Y range [1, 10]. A concrete range array defaults to scan:false and keeps auto:true.

Relevant configuration

const opts = {
  mode: 2,
  scales: {
    x: { time: false },
    // Restore these bounds on automatic recalculation, without a data scan.
    y: { range: [1, 10] },
  },
};
