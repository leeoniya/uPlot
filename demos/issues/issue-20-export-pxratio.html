Issue 20: per-instance export resolution

GitHub issue #20

This demo uses the current repository build. The published npm 1.6.32 does not include per-instance pixel ratio support.

Both charts render in detached containers. Each has a 480 × 240 logical size, but its own pixel ratio.

The exported PNGs appear at the same size here. Download them to compare their full resolutions.

const opts = {
  width: 480,
  height: 240,
  pxRatio: 4, // Produces a 1920 × 960 bitmap, regardless of browser DPR.
  legend: { show: false },
  scales: { x: { time: false } },
  series: [{}, { stroke: "blue" }],
};
