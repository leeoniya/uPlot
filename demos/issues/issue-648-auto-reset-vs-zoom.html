Issue 648: automatic Y reset versus explicit X zoom

GitHub issue #648

Expected: explicit X zoom preserves Y. setData(data, true) recalculates Y.

Relevant configuration

const opts = {
  scales: {
    x: { time: false },
    y: {
      // The default true value recalculates Y for each X change.
      // This callback preserves Y during an explicit X zoom and recalculates it after an automatic X reset.
      auto: (u, viaAutoScaleX) => viaAutoScaleX,
      // This identity ranger removes default Y padding, so displayed bounds equal scanned extrema.
      range: (u, min, max) => [min, max],
    },
  },
};
