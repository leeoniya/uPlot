Issue 648: automatic Y reset versus explicit X zoom

GitHub issue #648

Drag horizontally to zoom X without changing Y. Drag diagonally to zoom both axes. Double-click to restore both scales.

This behavior already works in the library. The default Y range includes padding. The data button recalculates both scales.

Relevant configuration

const opts = {
  cursor: {
    drag: { x: true, y: true, dist: 8, uni: 15 },
  },
  scales: {
    x: { time: false },
    // Recalculate Y on automatic X resets, not explicit X zoom.
    y: { auto: (u, viaAutoScaleX) => viaAutoScaleX },
  },
};
