Issue 655: preserve concrete bounds with auto disabled

GitHub issue #655

Drag horizontally to zoom X, then double-click to reset X. Y must stay at [-15, 15], with its axis and series visible.

This behavior predates scale.scan.

min and max establish the initial view, not permanent bounds or a reset target. auto: false prevents automatic Y recalculation after X zoom. Explicit Y changes still apply.

Relevant configuration

const opts = {
  scales: {
    x: { time: false },
    y: {
      auto: false,
      min: -15,
      max: 15,
    },
  },
};
