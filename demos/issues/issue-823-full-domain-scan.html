Issue 823: full-domain Y scan

GitHub issue #823

Drag horizontally to zoom X near [0, 1]. Y must stay at [10, 50]. Then click B in the legend: Y must expand to [10, 500], including values outside the zoom.

The custom scan uses the full domain of visible series. B starts hidden and is scanned when shown. Double-click to reset X; click B again to hide it.

Relevant configuration

const opts = {
  scales: {
    x: { time: false },
    y: {
      // Preserve Y during explicit X zoom instead of recalculating it by default.
      auto: (u, viaAutoScaleX) => viaAutoScaleX,
      // Use the full domain and populate the participating series caches.
      scan: (u, key) => uPlot.scan(u, key, null, null, true),
      // Remove padding so the displayed bounds equal the data extrema.
      range: (u, min, max) => [min, max],
    },
  },
  series: [
    {},
    { label: "A", stroke: "blue" },
    { label: "B", stroke: "red", show: false },
  ],
};
