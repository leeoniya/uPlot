Random labels: rotation and measured layout

Layout and bars use the reusable barChartPlugin.

The label rotation slider changes the angle without changing the random Y values. The longest displayed label determines the X axis height. Left/right padding uses each label’s width and position. Measurements stay cached until the labels, font, or pixel ratio changes.

Horizontal bars swap the chart dimensions, then reduce the height to one quarter. The data stays the same. Category labels stay unrotated on the left. Their measured width determines the space available for the numeric axis.

The two series appear side by side by default. Stack bars adds their values within each category. Percent shows each series as a share of the positive or negative total. The legend keeps the original values.

Randomize data generates 3–15 items with one-to-three-word labels made from adjectives, nouns, and verbs. Y values use random offsets and spreads across different magnitudes. For vertical bars, the Y axis measures its formatted labels to set its width. Grouped and value modes keep ticks at both Y bounds. Horizontal numeric ticks target 100px spacing. Soft zero limits keep the bar baseline visible in both orientations. Percent mode uses bounds of −100%, 0%, or 100%.

Distribution sets the gaps between category groups and at the plot edges. Group width sets each group’s width as a percentage of the plot dimension divided by the category count. Space around adds half a gap at each plot edge. Both controls keep the data unchanged.

Gray shows the space outside the plot. All labels stay visible; shallow angles can make neighboring labels overlap.
