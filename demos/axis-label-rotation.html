Random labels: rotation and measured layout

Layout and bars use the reusable barChartPlugin.

The slider changes label rotation without changing the random Y values. The longest displayed label determines the X axis height. Left/right padding uses each label’s width and position. Measurements stay cached until the labels, font, or pixel ratio changes.

Horizontal bars swap the chart dimensions, then reduce the height to one quarter. The data stays the same. Category labels stay unrotated on the left. Their measured width determines the space available for the numeric axis.

Randomize data generates 3–15 items with one-to-three-word labels made from adjectives, nouns, and verbs. Y values use random offsets and spreads across different magnitudes. For vertical bars, the Y axis measures its formatted labels to set its width. Tick-aware ranging keeps ticks at both Y bounds in either orientation. Horizontal numeric ticks target 100px spacing. Soft zero limits keep the bar baseline visible in both orientations.

Gray shows the space outside the plot. All labels stay visible; shallow angles can make neighboring labels overlap.
