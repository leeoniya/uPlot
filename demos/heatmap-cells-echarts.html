Sparse heatmap · ECharts 6.1.0

Native heatmap counterpart to the uPlot demo, using the same synthetic dataset (~250k generated cells) and colors. ECharts uses a local heatmap patch. Run node scripts/patch-echarts-heatmap.mjs to download and generate the library.

Equal-width time categories and equal-height exponential bucket categories preserve gaps and log-view spacing. Linear/asinh Y scales and negative mirroring are not supported here. Axis labels mark category centers; hover shows original cell bounds.
