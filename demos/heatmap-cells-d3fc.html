Sparse heatmap · D3FC 15.2.13 / D3 7.9.0

A native Canvas heatmap series using the same synthetic dataset (~250k generated cells) and colors as the uPlot, ECharts, and ECharts GL demos.

D3FC draws the sparse cells on UTC X and logarithmic Y scales. D3 supplies axes and rectangle-brush zoom; a binary search supplies cell hover. This comparison uses the positive log view only.
