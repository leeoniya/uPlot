Single-chart demos

Each page creates one chart with three series and 55,550 data points per series.

Pages use the benchmark adapters but construct directly with the full dataset. They do not run the automated benchmark phases.

Some demos are excluded from automated runs. Vendor license requirements and banners still apply.
