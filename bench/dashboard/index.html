Dashboard demos

Single-chart demos

Each page creates 20 charts in a 4×5 grid. Each chart has five series with 300 points per series.

The grid stays at 1920×1080 CSS pixels. Smaller browser windows scroll without scaling the charts.

Pages use the benchmark adapters, initialize with two rows, then update the same charts to 300 rows. They do not collect measurements.

Some WebGL variants can exceed browser context limits with 20 charts. Vendor license requirements and banners still apply.
