Canvas sprites: atlas vs separate canvases

Both methods draw the same translucent circles in the same order. Each cache contains five colors, not one canvas per dot.

Move the pointer over the canvas to reposition 100 dots. DPR is cached and refreshed after a zoom or display change.

The benchmark uses 100, 1,000, and 10,000 dots at DPR 1, 1.25, and 2. Keep this tab visible.

Each method gets 30 warmup frames and 120 measured frames. Test order alternates across six pairs of trials.

CPU time includes the clear and draw calls. It excludes position generation, cache creation, and readback. It does not measure completed GPU work.

Frame intervals include browser scheduling and display refresh limits. These intervals are not GPU timings. Pixel comparisons use separate, untimed canvases.
